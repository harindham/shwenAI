# shwenAI frontend

Next.js App Router frontend for shwenAI. The FastAPI backend remains in `../AI backend`.

## Requirements

- Node.js 18.17 or newer
- npm

## Run locally

From this directory:

```sh
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000). Edit `src/app/page.tsx` to update the home page.

The app uses TypeScript, Tailwind CSS, and ESLint. See the [Next.js documentation](https://nextjs.org/docs) for framework guidance.
